🔧 操作指南

快速上手 · WiFi 配网 · MQTT 配置 · 命令参考

1快速开始

设备上电后执行以下步骤：

  1. RGB 灯开机动画：白光快闪 3 次 → 彩虹 7 色轮播
  2. OLED 显示引导信息 "请打开串口监视器配置 WiFi 网络"
  3. 若 Flash 中有保存的 WiFi 凭据 → 自动连接（红灯常亮表示等待）
  4. 若无保存凭据或自动连接失败 → 进入串口配网流程
  5. WiFi 连接成功 → MQTT 自动连接 → RGB 绿灯呼吸

2WiFi 配网

打开串口监视器（115200 波特率），系统会自动扫描附近 WiFi 网络：

发现 5 个网络:
  [ 1]  TP-LINK_Home         RSSI: -45 dBm ( 85%)  加密
  [ 2]  CMCC-Free            RSSI: -72 dBm ( 30%)  开放
  ...

请输入网络序号 (0=跳过, 1 ~ 5): 1
已选择网络: TP-LINK_Home
请输入密码: ********

连接失败后可选择：R 重新输密码、S 重新扫描、Q 跳过 WiFi。

连接成功后凭据自动保存到 Flash，下次上电自动连接。

3按键操作

按键操作功能
KEY1（总闸）按下 / 释放按下=开机运行，释放=全部复位关机
KEY2（模式）短按手动模式下循环切换：全关→风扇→灯→全开
KEY2（模式）长按 0.5s切换自动/手动模式

5串口命令参考

WiFi 命令

wifi → 重新扫描选网配网
forget → 清除 Flash WiFi 凭据，自动进入配网

MQTT 命令

mqtt → 查看当前 MQTT 配置
mqtt host 192.168.1.100 → 设置服务器 IP
mqtt port 1883 → 设置端口
mqtt id PCT_100_XXX → 设置设备 ID
mqtt test → 测试当前参数能否连通（不保存）
mqtt save → 保存到 Flash 并重连
mqtt clear → 清除 Flash MQTT 配置
mqtt stop → 手动断开 MQTT（不再自动重连）
mqtt start → 恢复自动重连

系统命令

status → 显示系统状态（温度/光照/继电器/WiFi）
help → 显示命令帮助

行显示内容说明

第2行WiFi:OK/NO MQTT:OK/NO网络连接状态
第3行光照: XXX/XXX lx当前值 / 阈值
第4行温度: XX.X/XX.X ℃当前值 / 阈值
